An alternative app to watch Twitch on Android TV devices.

## Features

- Ad-free streaming via token-based resolution — direct from Twitch CDN, no proxy
- Overlay chat with BTTV, 7TV, FFZ emote support
- Followed channels, top streams, category browsing
- Channel search
- Watch time, channel points auto-claim, drop tracking
- Recently watched history
- Per-channel source preferences
- In-app automatic updates

## Installation

**Easy method:** Use the [Downloader](https://www.downloader.firetv.com/) app and enter the URL to the latest APK from the [Releases](https://github.com/crpz2/W4tchTV/releases) page.

**Manual:** Sideload the latest APK directly to your device.

---

## Releases

APKs are attached to each [GitHub Release](https://github.com/crpz2/W4tchTV-releases/releases). The app checks for updates automatically.
